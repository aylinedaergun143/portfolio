01

Project Statement

Stitch is a product-service system that creates a safe and gamified interaction environment, building bridges between travelers and locals through opportunities for value and skill exchanges.

As the application is used, a network is woven between the places visited by users through the spider mascot “Stitch.”

Each user is accompanied by a two-part badge

  1. One part contains a Bluetooth tracking device and remains with the user.
  2. The other badge is exchanged with people they connect with, enabling the network to expand.
02

System and Safety Ecosystem

This product-service system prioritizes user safety throughout all stages of the journey by integrating emergency stakeholders and safety precautions.

Safety Settings

Users define permissions for emergency stakeholders. Police, ambulance and firefighters can be reached when necessary.

Stitch Application

My Web

Users join paths, exchange badges and tie new knots. Each exchange expands both participants’ networks.

The Charm

A Bluetooth tracker detects stability, movement and emergency-button input, then shares location data with the application.

Journey Safety

Joining paths connects applications, pre-arrival preparation, arrival checks and post-journey feedback.

Continuous Network

Badge journeys are stored while new owners, knots and shared paths continue to grow My Web.

Frictionless & Personalized Matching

The framework prioritizes user-centric filtering, map-based discovery, and fast application flows to seamlessly connect travelers with host organizations and short-term micro-contributions.

Hyper-Local & Continuous Community

The system fosters authentic local immersion through guided experiences and local events while sustaining traveler connections before, during, and after projects.
